# k-realty-yield

한국 부동산 임대수익률 계산기 — **값이 아니라 값의 나이까지 준다.**

> Korean real-estate yield calculator. Every institutional figure carries its **layer** (statute → enforcement decree → administrative guidance) and **verification date**. Where the written rule and the applied value differ, it shows **both**. Calculation engine works offline with no API key.

---

## 왜 하나 더 만들었나

시중 수익률 계산기는 값을 하드코딩한다. LTV 70%, 취득세 4.6%, 금리 4%. 그리고 **언제 기준인지 안 적는다.**

**실측 사례** — 은행업감독규정 별표6의 담보인정비율은 지금도 **70%(규제지역 50%)**로 적혀 있는데, 실제 적용값은 **행정지도**로 정해진다. 2025년 10월 기준 **40%**였고, 별표6은 그 뒤 **두 차례 개정되면서도 이 숫자를 손대지 않았다.**

**조문을 정확히 찾은 사람이 10%p 틀린 값을 확신과 함께 얻는다.**

그래서 이 도구는 숫자만 주지 않는다.

```
[T-대출-02] ⚠⚠ 규정값 50% ≠ 실제 적용값 40% — 조문만 보면 틀립니다.
[T-취득-01] 시행일 미확인 — 현재값은 맞으나 소급 계산에 쓸 수 없습니다.
```

## 무엇을 하나

**표면 5%가 실제로 얼마가 되는지** 단계별로 분해한다.

```
Ⓞ 문헌의 자          5.00%
① 취득 부대비용       4.70%  (낙차 0.30%p)
② 공실              4.31%  (낙차 0.39%p)
③ 보유·운영비         3.97%  (낙차 0.34%p)
④ 재계약 중개보수      3.75%  (낙차 0.22%p)
⑤ 임대소득세          2.76%  (낙차 0.99%p)
```

**55%만 남고, 사라진 몫의 44%가 세금이다.** 그리고 **공실 두 달의 낙차가 취득세·중개보수·등기비를 전부 합친 것보다 크다.**

대출이 있으면 **점추정 대신 구간**을 낸다.

```
금리 3.36%   ROE +13.12%   ROA 4%
금리 4.36%   ROE  +5.12%   ROA 4%
금리 5.36%   ROE  -2.88%   ROA 4%   ← 부호가 뒤집힌다
```

**자산수익률 칸이 한 번도 안 움직이는 것**이 이 표의 요점이다. 대출은 물건의 수익을 키우지 않고 **자산수익률과 금리의 차이에 지렛대를 걸 뿐**이다.

## 빠른 시작

```bash
git clone https://github.com/dillettante/k-realty-yield
cd k-realty-yield
python3 tests/test_worked_examples.py   # 의존 없음 — 바로 돈다
```

```python
from engine.yield_basic import Property, five_measures, net_yield_steps

p = Property(price=200_000_000, deposit=20_000_000, monthly_rent=750_000,
             acquisition_tax=9_200_000, broker_fee_buy=1_800_000,
             vacancy_months=1.0, holding_cost_yearly=650_000,
             rent_tax_rate=0.264)

for s in net_yield_steps(p):
    print(f"{s.label:<16} {s.rate:6.2%}  (낙차 {s.drop*100:.2f}%p)")
```

**API 키가 없어도 전부 동작한다.** 키는 기본값을 시장 실측으로 바꿔 주는 편의일 뿐이다.

## 시장 데이터 (선택)

```bash
python3 data/collect_ecos.py                      # 금리 — 시험키로도 동작
ECOS_API_KEY=... python3 data/collect_ecos.py     # 전 구간
REB_API_KEY=...  python3 data/collect_reb.py      # 공실률·순영업소득
```

⭐ **기준금리 하나로 법정값이 유도된다** — 전월세 전환율 상한이 그것이다. **법도 시행령도 안 고치고 금융통화위원회가 값을 움직인다.**

⚠⚠ 다만 **상한이 둘이고 낮은 쪽이 이긴다.** 그리고 **주택과 상가는 식 자체가 다르다.**

| | 상한 | 기준금리 연동분 | 근거 |
|:---|:---:|:---|:---|
| 주택 | 연 **1할** | 기준금리 **+ 2%p** | 주택임대차보호법 제7조의2·시행령 제9조 |
| 상가 | 연 **1할2푼** | 기준금리 **× 4.5배** | 상가건물 임대차보호법 제12조·시행령 제5조 |

기준금리 2.75%면 **주택 4.75% · 상가 12.0%로 7.25%p 벌어진다.** 「기준금리 + 2%p」 하나만 아는 채로 상가에 쓰면 크게 틀린다.

키 발급처는 [`API_KEYS.md`](API_KEYS.md).

### ⚠ 데이터는 배포하지 않는다

**수집 코드만 있고 수집물은 없다**(`cache/`는 `.gitignore`). 편의가 아니라 법적 요건이다 — 한국부동산원 등 **공공기관 저작물은 저작권법 제24조의2 제1항의 자유이용 대상이 아니다**(자유이용은 국가·지방자치단체 한정). 이용자가 자기 키로 받고, 이용조건은 각 기관 것을 따른다.

## 하지 않는 것

| | | 강제 |
|:---|:---|:---:|
| **물건을 고르지 않는다** | 추천·순위·검색 기능이 **코드에 없다** | 부재 |
| **시점을 고르지 않는다** | 매수·매도 신호가 **없다** | 부재 |
| **단일 답을 주지 않는다** | 금리·공실·세율은 구간과 민감도로 | ⚠ 지시 |
| **예측하지 않는다** | 상승률 가정을 기본값에 두지 않는다 | 부재 |

**셋은 만들지 않아서 못 하고, 하나는 지시로 지킨다.** ⚠ 「단일 답을 주지 않는다」는 코드가 막는 것이 아니라 `SKILL.md`가 시키는 것이다 — 구별해서 읽어야 한다.

**개인이 무상으로 공개하는 도구**이며 **법률·세무·투자 자문이 아니다.** 이용하거나 이슈로 소통해도 자문관계가 성립하지 않는다 → [`DISCLAIMER.md`](DISCLAIMER.md)

## 값의 수명

| 층 | 무엇 | 누가 바꾸나 | 만료 |
|:---:|:---|:---|:---:|
| `L1` | 법률 | 국회 | 12개월 |
| `L2` | 시행령·시행규칙 | 정부 단독 | 6개월 |
| `L3` | 고시·감독규정 | 기관 | 3개월 |
| **`L4`** | **행정지도** | **발표 하나로** | **1개월** |
| `L5`·`L6` | 기관 요건·실무 관행 | — | **값을 싣지 않는다** |

`L5`·`L6`은 A등급 출처가 없어 **값 대신 「어디서 확인하는가」만** 적는다. 명도비용·중개 관행·은행별 가산금리가 여기 속하고 **사용자 입력**으로 받는다.

만료돼도 **계산을 막지 않는다** — 막으면 더 낡은 계산기로 가기 때문이다. 대신 경고를 붙이고, 30일을 넘기면 직접 입력을 요구한다.

갱신 절차 → [`MAINTENANCE.md`](MAINTENANCE.md) (월 1회, 실제 대상은 `L4` 넷)

## 출처

**새로 만든 식은 없다.** 세 곳에서 왔고, 셋 다 확인 가능한 것이다.

| | 무엇 | 어디서 |
|:---|:---|:---|
| **계산식** | 다섯 셈법 | 국내 부동산 실무서 — 안민석(32·103쪽)·이고은(73쪽)·송희창(181·182쪽)·너나위(68쪽) |
| | 레버리지 항등식 | 표준 재무식. 대차대조표 항등식에서 유도된다 |
| **제도 값** | 취득세·보유세·양도세·임대차·LTV | **국가법령정보센터 조문 원문.** 각 항목의 `basis`가 그 조문이다 |
| | LTV 실제 적용값(`L4`) | 금융위원회 보도자료 — 조문이 없어서 |

`tests/test_worked_examples.py`가 **손으로 검산한 예제**로 엔진을 지킨다. 기대값은 따로 손계산해 넣은 것이지 코드 출력을 굳힌 것이 아니다.

⚠ **허용치는 칸마다 다르다.** 수익률·ROE 같은 핵심 칸은 **0.01%p 이내**이고, 파생 비율(잔존율 55%·세금 몫 44%)은 ±1%p, 금액 칸은 ±5,000원이다. 「전부 0.01%p」가 아니다.

**「다섯 셈법」이 이 도구의 출발점이다.** 위 책들이 저마다 「수익률」이라는 한 낱말을 쓰는데 **분모가 서로 다르다.** 실측한 국내 재테크서 45권에 **「표면수익률」이라는 낱말 자체가 0회**였다 — 이름 없이 쓰이니 독자는 자기가 어느 자를 보는지 모른다. 그래서 이 도구는 첫 화면에 다섯을 **동시에** 낸다.
